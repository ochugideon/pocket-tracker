About This App

The Smart Student Savings Planner is a practical web application built by JSS 2 students of TEEVES INT'L SCHOOLS to help students track their daily spendings and estimate weekly savings based on daily allowance. It combines basic financial literacy with fundamental web programming.

By using this tool, students learn to calculate daily allowances, track break-time snack spending, and set targets for weekly savings toward essential items like books, pens, and footwear.

Key Topics Demonstrated:
Operators & Conditionals Loops & Functions DOM Manipulation Events & Interactivity
